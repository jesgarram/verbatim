# Presentation Mode

The speaker had their own structure — a talk, a demo walkthrough, a prepared presentation. Respect it.

## Structuring Rules

1. **Preserve the speaker's existing flow.** Don't reorganize — the speaker chose this order for a reason. Only adjust when the spoken order was clearly a tangent that loops back.

2. **Smooth transitions, don't replace them.** In a talk, the speaker uses verbal transitions ("So now let's look at...", "Okay, moving on..."). Convert these to written transitions that serve the same purpose but read naturally. Don't drop them and leave disconnected sections.

3. **Keep demo/example sequences intact.** If the speaker walked through an example step by step, preserve that progression. The example IS the explanation.

4. **Section breaks at topic shifts.** The speaker's pauses and "okay, so" moments usually mark section boundaries. Use those, not imposed structure.

5. **Preserve the speaker's emphasis hierarchy.** What they spent the most time on is what they care most about. Don't flatten by giving equal weight to every topic.

6. **Opening**: If the talk had a grabby opening, keep it. If it started with pleasantries or housekeeping ("Hi everyone, welcome to..."), skip to where the content begins — but still look for the best hook from anywhere in the talk.

7. **Closing**: Keep the speaker's actual conclusion. Don't add a summary they didn't give. If the talk trailed off, find the last substantive point and end there.
