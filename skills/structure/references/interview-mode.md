# Interview Mode

The speaker was responding to questions — their ideas are scattered across answers, shaped by what the interviewer asked. The goal is to extract a coherent solo narrative.

## Structuring Rules

1. **Remove the interviewer entirely.** The output should read as if the speaker wrote it themselves. No "Q:" / "A:" format, no "When asked about...", no trace of the interview structure.

2. **Identify speaker lines.** If the transcript has speaker labels (SPEAKER_00, SPEAKER_01, etc.), determine which is the primary speaker (the interviewee — usually the one giving longer, substantive answers) and extract only their content.

3. **Patch scattered answers.** The speaker may have addressed the same topic across multiple answers (because the interviewer circled back, or because the speaker referenced it again later). Merge these into a single coherent section.

4. **Recover implied context.** When the speaker says "Yes, exactly" or "That's a good question" — they're responding to something. If the answer doesn't make sense without the question, weave the necessary context into the speaker's own words. Don't invent — infer from what the speaker said next.

5. **Reorder for narrative flow.** Interview order is driven by the interviewer's agenda, not the speaker's natural argument. Reorganize sections so the speaker's ideas build on each other logically:
   - Start with the core problem/motivation
   - Build through the solution/approach
   - Add nuance, edge cases, philosophy
   - End with the takeaway

6. **Preserve the speaker's digressions** when they're interesting. An aside that reveals personality or offers a good anecdote should stay — even if it was "off topic" for the interview.

7. **Don't clean up the interviewer's framing.** If the interviewer introduced a concept with fancy language but the speaker responded in plain terms, use the speaker's language, not the interviewer's.
