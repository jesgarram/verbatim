# Anti-Slop: Banned Phrases

These phrases signal AI-generated content. If any appear in the output, replace them with the speaker's natural language or cut the sentence entirely. No exceptions.

## AI Transition & Structure Slop

- "let's dive in" / "dive deep" / "deep dive"
- "without further ado"
- "in conclusion" / "to summarize" / "to wrap up"
- "now let's turn our attention to"
- "with that said" / "that being said"
- "let's explore" / "let's examine"
- "it's worth noting" / "it's important to note" / "it bears mentioning"
- "interestingly enough"
- "as we'll see" / "as mentioned earlier"
- "moving on" / "shifting gears"

## AI Hype Slop

- "game-changer" / "game-changing"
- "revolutionary" / "revolutionize"
- "groundbreaking"
- "cutting-edge" / "bleeding-edge"
- "paradigm shift"
- "transformative" / "transform" (unless literal)
- "empower" / "empowering"
- "unlock" (unlock potential, unlock value, etc.)
- "supercharge"

## AI Business Slop

- "leverage" (as a verb)
- "synergy" / "synergize"
- "stakeholders" (use "people involved")
- "actionable insights" (use "things you can do")
- "best practices" (use "what works")
- "thought leader" / "thought leadership"
- "value proposition"
- "scalable" (unless about actual systems)
- "streamline"
- "optimize" (unless about actual performance)

## AI Description Slop

- "in today's rapidly evolving landscape"
- "the landscape of" / "the ecosystem of"
- "navigate" (navigate challenges, navigate complexity)
- "harness" (harness the power)
- "holistic"
- "robust" (unless about actual engineering)
- "seamless" / "seamlessly"
- "pivotal"
- "cornerstone"
- "spearhead"
- "bolster"
- "foster" (foster innovation, foster collaboration)
- "elevate"
- "delve into"
- "unpack" (as in explain)
- "nuanced" (when used as filler praise)
- "at the end of the day"

## AI Emotional Slop

- "incredibly" / "unbelievably" (as intensifiers)
- "passionate about"
- "excited to announce" / "thrilled to share"
- "journey" (our journey, this journey)
- "resonates" / "resonates with"
- "impactful"

## AI Formatting Slop

- Em-dashes (—) — replace with commas, periods, or parentheses. The speaker uses plain punctuation, not typographic flourishes.

## Test

If a phrase sounds like it could appear on LinkedIn, in a press release, or in a ChatGPT-generated blog post — it's probably slop. Cut it.

The speaker's actual words are always better than polished alternatives. "This thing is really cool" beats "This is a particularly noteworthy development" every time.
